# 逢甲選課手帳

用 [Astro](https://astro.build) 做的靜態站，資料來自本 repo 的 `data/`。

## 簽名互動：先貼上去看看

**滑過任一門課，它就先以半透明貼紙貼進右上角的小課表**，撞到既有課程的格子立刻轉成
珊瑚紅，下方同步給出一句判決——

> 會跟「體育(一)」撞在一起
> 經濟學(一) 貼得下，不會撞課

「這門課塞不塞得下」因此變成零點擊就能看見的事。官方系統要先加進「關注清單」才看得到。

## 比官方好用的地方

官方每次查詢都要 postback 一次伺服器，而且得先一層層選完學年度 → 學期 → 學制 →
學院 → 系所 → 班級才查得到東西。這裡把整個學期的資料（gzip 後約 135 KB）一次載進
瀏覽器，之後全部在本機跑：

- **打字即時出結果**，搜尋與課表預覽都在本機執行，不需要任何搜尋函式庫
- **一個搜尋框**同時比對課名、教師、課號、教室、班級、備註
- **點課表空格**就能查「週三第 6 節有什麼課」
- **避開衝堂**：開啟後只列出排得進現有課表的課
- **選課人數畫成點點**，一眼看出還有沒有位子
- **查詢條件全在網址上**，可以直接分享／加書籤
- 課表存在 localStorage，關掉瀏覽器不會不見
- `/` 聚焦搜尋、`Esc` 清空

## 設計規格

| | |
| --- | --- |
| 底色 | `#FDF6E9` 暖米，卡片 `#FFFDF8`，字 `#4A4239` 暖棕黑（不用純黑） |
| 貼紙色 | 6 個粉彩循環，依課號雜湊決定，增刪課程時顏色不會亂跳 |
| 衝堂 | `#E0785C` 珊瑚紅，是整站唯一的警示色 |
| 形狀 | 圓角 14px、膠囊按鈕、柔和陰影，全站沒有一條硬邊框 |
| 拉丁字 | Nunito 可變字重（38 KB latin 子集，自行 host） |
| 中文 | 系統字（PingFang TC / Noto Sans TC / 微軟正黑），不載 CJK webfont |

CJK webfont 動輒 5–10 MB，跟「一次載完整學期只要 135 KB」的前提直接衝突，所以中文
一律走系統字，圓潤感交給 Nunito、圓角與粉彩去撐。

## 開發

```bash
cd site
npm ci
npm run dev      # 會先把 ../data 複製到 public/data
npm run build
```

`public/data/` 是從 `../data/` 複製過來的建置產物，已列入 `.gitignore`。

## 部署

推到 `master` 且 `site/**` 或 `data/**` 有變動時，`.github/workflows/pages.yml`
會自動建置並部署到 GitHub Pages；每日資料更新 workflow 成功後也會重新部署。首次使用需要先在
**Settings → Pages → Source** 選 **GitHub Actions**。

站台網址為 `https://heitang.github.io/FCU-CourseData/`，若要換路徑請同步改
`astro.config.mjs` 的 `site` 與 `base`。
